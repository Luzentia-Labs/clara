## What the review changes about how this project works

1. **A guard ships with its fail-proof in the same commit.** Not "later" - three guards went a full
   run unproven and all three were broken.
2. **Stop hand-rolling parsers.** This was the sixth and seventh instance. `lib/workflow.mjs` uses a
   real YAML parser; `lib/exports-read.mjs` and the CSS brace walk are now tested against the shapes
   that defeated them.
3. **Fixing a defect means fixing the class.** The substring bug was fixed in one guard and left in
   its sibling, in the same session.
